# Roomy downloads

Finished installers for **Roomy**, the calm disk cleaner for Mac and Windows. Get the newest version from **Releases**.

- **Mac:** `Roomy-…-Mac-AppleSilicon.zip` (Apple chips) or `Roomy-…-Mac-Intel.zip`
- **Windows:** `Roomy-…-Windows-Setup.exe` (installs and updates itself) or `Roomy-…-Windows-portable.exe`

Installed copies of Roomy check this page for updates. The app's code is not here.
